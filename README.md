# SWYNEX Interactive Dashboard – Crime Analytics (Task 3)

Interactive Power BI dashboard built on the cleaned crime dataset from Tasks 1–2.

## Dataset
5,050 incidents (2018–2024): crime type, district, severity, case status, resolution, weapon, property loss, arrests. Personal identifiers were removed.

## Dashboard
- KPIs: total incidents, total property loss, arrest rate, critical %, average loss
- Visuals: yearly trend, crime types, severity, loss by district, resolution vs case status, victim age groups, weapons
- Filters: crime type and year

## Key insights
- Fraud is the most common crime (437 incidents).
- Total reported property loss is about $115.2M (about $22.8K per incident).
- About 28% of all incidents ended in an arrest.
- Incident volume is stable year to year (642–706).
